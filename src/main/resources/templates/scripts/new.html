📚 Доступные переменные в скрипте
Основные переменные:
  • cdDiskService - сервис для работы с CD дисками
  • scriptName - полный путь скрипта
  • scriptPath - полный путь скрипта (alias)
  • scriptBaseName - имя файла без расширения
  • executionTime - время выполнения скрипта
  • timestamp - время выполнения (alias)
Методы cdDiskService:
  • findAll() - получить все CD диски
  • findById(id) - найти диск по ID
  • save(cdDisk) - сохранить/обновить диск
  • deleteById(id) - удалить диск по ID
  • existsById(id) - проверить существование
Вспомогательные функции:
  • println(message) - вывод в консоль
  • print(message) - вывод без перевода строки
  • json - парсер JSON (json.parseText())
  • toJson(obj) - преобразование в JSON строку
Примеры использования:
// Получить все диски
def disks = cdDiskService.findAll()

// Найти диск по ID
def disk = cdDiskService.findById(1)

// Создать новый диск
def newDisk = new CdDisk(title: "Альбом", artist: "Исполнитель", year: 2024)
cdDiskService.save(newDisk)

// Вывод информации
println "Скрипт: \$scriptName"
println "Выполнен: \$executionTime"

// Возврат результата
return [
    success: true,
    diskCount: disks.size(),
    script: scriptName,
    time: timestamp
]
